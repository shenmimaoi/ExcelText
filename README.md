## 工具说明

### 1. Excel数据清洗匹配.exe

**成品编号清洗匹配工具** —— 把表格里写法不规范的编号，自动匹配到规范写法。

#### 清洗规则（自动执行）

覆盖各种「看起来一样、实际码点不同」的坑：

- **去除所有空白**：半角/全角空格、NBSP（U+00A0）、制表符、零宽字符（U+200B 等）
- **全角转半角**（NFKC）：全角字母数字、全角横杠 `－` → `-`
- **英寸符号统一**：`”` `″` `"` → `in`（`7”Plate` → `7inPlate`）
- **各种横杠统一**：`–` `—` `−` `‐` → `-`
- **中文括号转英文**：`（）` → `()`

#### 匹配规则（10 级，按可信度依次尝试）

| 优先级 | 规则 | 示例 |
|---|---|---|
| 1 | 精确 | `ABC` = `ABC` |
| 2 | 英寸 → in | `7"Plate` = `7inPlate` |
| 3 | 英寸去除 | `7"Plate` = `7Plate` |
| 4 | 去尾部序号 | `123-1` = `123`（双向） |
| 5 | 去全部尾部序号 | `123-1-2` → `123` |
| 6 | 去尾部序号 + 去横杠 | |
| 7 | 括号内外互换 | `123(FC2002)` = `FC2002(123)` |
| 8 | 去括号内容 | `DRBSS` = `DRBSS(FCS)` |
| 9 | 去横杠 | `12-3` → `123` |
| 10 | 数字去前导零 | `650090` = `0650090` |

#### 输出

在目标列右侧插入三列，**原有格式与其他列一律保留**：

- `清洗后编号` —— 标准化后的值
- `正确成品编号` —— 匹配到的规范写法
- `匹配状态` —— 命中了哪条规则（如 `匹配(英寸→in)`），未匹配则标 `未匹配`

**不会覆盖原文件**，另存为 `原名_编号匹配后.xlsx`。

#### 可诊断性

- 每行写明命中规则，可按此列**筛选复核**
- 未匹配的行会在运行日志中列出，便于补充对照表
- 同一写法对应多个不同结果时，按规则择优**并告警**，不静默乱选

### 2. 批量改Excel字段下信息.exe

批量修改 Excel 中指定字段（列）下的信息。

## 使用方法

1. 到 [Releases](../../releases) 下载需要的 `.exe`
2. 双击运行（Windows）
3. 按界面提示选择文件、填写列名、点击「开始处理」

> 首次运行如被 Windows Defender / SmartScreen 拦截，属未签名程序的常见提示，选择「仍要运行」即可。

## 运行环境

- Windows 10 / 11（64 位）
- 无需安装 Python 或其他依赖（已打包为独立可执行文件）
